Clean the data

To clean the data, remove any rows that shouldn’t be analyzed, and keep only the columns that we will use:

### Remove the "preview" participant
data_clean <- data_raw |> filter(DistributionChannel != "preview")

### Keep only the columns we are interested in: perception of others' choices (%), and participants' own choice (Individual papers, Group papers)
### Keep "ResponseID" as an ID for each subject.
### Q4: % voting for group; Q8: % voting for individual; Q5: own choice
data_clean <- data_clean |> select(ResponseId, Q4, Q8, Q5)

## Give these variables more meaningful names (You don't have to use the same names as the example)
data_clean <- data_clean |> rename(perception_group = Q4, perception_individual = Q8, own_choice = Q5)
